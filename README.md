# ReachRich

ReachRich 是面向 A 股市场的研究平台。本仓库提供产品介绍、研究方法资料和使用手册入口。

[打开 ReachRich](https://reachrich.ai/) · [了解平台](https://reachrich.ai/about) · [使用手册](https://docs.reachrich.ai/) · [帮助与反馈](https://reachrich.ai/support)

## 一份可复核的资料记录

拿到一条行情或一份公司材料时，先记下证券代码、原始来源、数据日期、首次可得时间、价格复权口径和本次研究问题。把事实摘录与自己的判断分开，下一次比较时沿用同一口径。

这份记录可以放进自己的研究笔记，也可以作为向 RiQi 提问的上下文；不需要先把结论写成买卖信号。

## ReachRich 与 RiQi

ReachRich 提供平台入口与研究资料；[RiQi](https://riqi.ai/) 是投研助手，用于围绕材料梳理问题、核对来源并继续追问。[从一次公司研究开始](https://riqi.ai/research/a-share-company-research.html)。

本仓库提供产品介绍与研究方法资料，不包含产品后端、生产数据或私有策略。当前商业化面向 A 股，港股与美股仍在研发。
