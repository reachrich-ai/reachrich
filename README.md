ReachRich 将行情、资讯与筛选工具放在同一研究平台，供个人研究者和机构投研团队查看市场、建立候选清单，再围绕具体标的继续研究。[RiQi](https://github.com/reachrich-ai/riqi) 是同一产品体系中的 AI 投研助手，承接提问、材料讨论与后续追问。

## 按研究任务开始

| 研究任务 | 使用路径 |
| :--- | :--- |
| 查看个股价格与成交情况 | [查询日 K](https://docs.reachrich.ai/reachrich/daily-k.html)，或[切换日、周、月周期](https://docs.reachrich.ai/reachrich/weekly-monthly.html) |
| 从新闻找到研究线索 | [搜索资讯、选择来源与分类](https://docs.reachrich.ai/reachrich/news.html)，再核对原始报道与公告 |
| 建立候选股票池 | [使用筛选模板](https://docs.reachrich.ai/reachrich/screener.html)，记录条件并比较候选结果 |
| 深入研究一家公司 | [按公司研究流程整理问题与材料](https://docs.reachrich.ai/workflows/company-study.html)，在 [RiQi](https://riqi.ai/) 中继续讨论 |

第一次使用，可从[完成你的第一次 A 股研究](https://docs.reachrich.ai/start/quickstart.html)开始。已有明确任务，直接查阅[完整手册](https://docs.reachrich.ai/)。

## 研究专题

| 专题 | 重点 |
| :--- | :--- |
| [A 股回测：交易成本与复权口径](https://reachrich.ai/research/a-share-backtest-costs.html) | 核对交易假设、费用、复权与样本外结果，理解回测之间的差异 |
| [A 股新闻事件研究：从资讯线索到公司公告](https://reachrich.ai/research/a-share-news-event-study.html) | 对齐报道与事件日期，从新闻线索回到原始材料 |
| [A 股因子验证：识别过拟合与样本外失效](https://reachrich.ai/research/a-share-factor-validation.html) | 记录参数尝试、划分验证区间，检查结论是否依赖已知样本 |

研究专题解释方法与判断依据；手册说明具体操作。公司研究示例见[用 RiQi 做 A 股公司研究](https://riqi.ai/research/a-share-company-research.html)。

- **RiQi**：[产品介绍](https://reachrich.ai/riqi)与[对话式研究工作区](https://riqi.ai/)。

本仓库发布产品介绍与公开指南，不包含产品核心代码或私有策略。
