ReachRich 是面向 A 股市场的量化研究平台，为个人研究者和机构投研团队提供行情、资讯与股票筛选工具。[RiQi](https://github.com/reachrich-ai/riqi) 是配套的 AI 投研助手，用于围绕公司与研究资料展开对话。

[打开 ReachRich](https://reachrich.ai/) · [使用手册](https://docs.reachrich.ai/) · [平台介绍](https://reachrich.ai/about) · [English](README.en.md)

## 开始使用

1. **了解市场。** 查看指数与涨跌分布，查询关注公司的价格和成交量。
2. **形成候选。** 从新闻线索或筛选模板入手，记录研究对象、条件与数据日期。
3. **深入研究。** 将相关公告和具体问题带入 [RiQi](https://riqi.ai/)，讨论经营变化，继续核对回答中的依据。

完整操作见[第一次 A 股研究](https://docs.reachrich.ai/start/quickstart.html)和[公司研究流程](https://docs.reachrich.ai/workflows/company-study.html)。

## 主要功能

- **行情观察**：结合价格与成交量查看个股走势，切换[日 K](https://docs.reachrich.ai/reachrich/daily-k.html)及[周、月周期](https://docs.reachrich.ai/reachrich/weekly-monthly.html)。
- **资讯研究**：按关键词、来源和分类查找新闻，再核对相关公告与原始披露。[操作指南](https://docs.reachrich.ai/reachrich/news.html)
- **股票筛选**：使用模板建立候选清单，保留所用条件和数据日期，选择需要进一步研究的公司。[操作指南](https://docs.reachrich.ai/reachrich/screener.html)
- **对话式研究**：在 RiQi 中讨论资料、追问依据，并在原会话中补充后续信息。[了解 RiQi](https://reachrich.ai/riqi)

## 研究指南

- [A 股回测：交易成本与复权口径](https://reachrich.ai/research/a-share-backtest-costs.html)：比较价格口径、成交假设、换手定义与样本外结果。
- [从资讯线索到公司公告](https://reachrich.ai/research/a-share-news-event-study.html)：对齐报道与事件日期，整理原始材料与后续观察点。
- [因子验证与过拟合](https://reachrich.ai/research/a-share-factor-validation.html)：记录参数尝试，固定验证区间，检查成本和成交约束。
- [用 RiQi 做 A 股公司研究](https://riqi.ai/research/a-share-company-research.html)：从公告材料到持续追问的具体用法。
